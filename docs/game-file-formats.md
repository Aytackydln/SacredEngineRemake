## How coverage is calculated

Field coverage is the percentage of serialized fields whose purpose has a meaningful name. Byte coverage is the percentage of bytes covered by those fields. Fields marked `BinaryUnknown`, fields named `Unknown…`, and gaps between fields remain unknown. Overlapping known fields count each byte once. Fixed-width strings use `BinaryString` metadata so the report treats the whole encoded range as one field.

Percentages describe the fixed-size structures represented in `Sacred.Core`; repetitions are not weighted by one particular game installation. Variable-size image, sound, Granny, compressed, and string payloads are excluded where their internal byte layout is not a fixed `StructLayout` type.

## File structures

### `pak/Items*.pak`

Item visuals and model references.

- Header: [`ItemsPakHeaderLayout`](#itemspakheaderlayout) — once, 0x102 bytes
- Entry descriptors: [`ItemsPakEntryInfoLayout`](#itemspakentryinfolayout) — EntryCount times, 0xC bytes
- Model descriptions: [`ItemsPakEntryModelDescLayout`](#itemspakentrymodeldesclayout) — one per populated descriptor, 0x80 bytes

### `pak/Weapon.pak`

Equipment definitions and damage ranges.

- Header: [`WeaponPakHeaderLayout`](#weaponpakheaderlayout) — once, 0x102 bytes
- Equipment records: [`SacredEquipmentLayout`](#sacredequipmentlayout) — EntryCount times, 0x102 bytes

### `pak/texture*.pak`

Texture metadata and encoded pixel payloads.

- Header: [`PakArchiveHeaderLayout`](#pakarchiveheaderlayout) — once, 0x100 bytes
- Entry descriptors: [`PakEntryDescriptorLayout`](#pakentrydescriptorlayout) — EntryCount times, 0xC bytes
- Texture headers: [`TexturePakEntryHeaderLayout`](#texturepakentryheaderlayout) — one per populated descriptor, 0x50 bytes. Encoded pixel payload bytes are variable-size and excluded from fixed-layout coverage.

### `pak/mixed.pak`

Composite sprite groups.

- Header: [`PakArchiveHeaderLayout`](#pakarchiveheaderlayout) — once, 0x100 bytes
- Entry descriptors: [`PakEntryDescriptorLayout`](#pakentrydescriptorlayout) — EntryCount times, 0xC bytes
- Group headers: [`MixedPakGroupLayout`](#mixedpakgrouplayout) — one per populated descriptor, 0x10 bytes
- Sprite pieces: [`MixedPakPieceLayout`](#mixedpakpiecelayout) — PieceCount times per group, 0x40 bytes

### `pak/models*.pak`

Model archive and known payload metadata.

- Header: [`PakArchiveHeaderLayout`](#pakarchiveheaderlayout) — once, 0x100 bytes
- Entry descriptors: [`ModelPakDescriptorLayout`](#modelpakdescriptorlayout) — EntryCount times, 0xC bytes
- Known payload metadata: [`ModelPakPayloadMetadataLayout`](#modelpakpayloadmetadatalayout) — one per sufficiently large payload, 0x47C bytes. Variable-size Granny model data is excluded from fixed-layout coverage.

### `pak/Models.tmp`

Model-to-motion companion metadata.

- Header: [`ModelsMetadataHeaderLayout`](#modelsmetadataheaderlayout) — once, 0x118 bytes
- Model records: [`ModelsMetadataModelLayout`](#modelsmetadatamodellayout) — ModelCount times, 0x4AA bytes
- Motion-name records: [`ModelsMetadataMotionLayout`](#modelsmetadatamotionlayout) — MotionCount times, 0x100 bytes

### `pak/tiles.pak`

Terrain tile definitions.

- Header: [`PakArchiveHeaderLayout`](#pakarchiveheaderlayout) — once, 0x100 bytes
- Entry descriptors: [`PakEntryDescriptorLayout`](#pakentrydescriptorlayout) — EntryCount times, 0xC bytes
- Known tile prefix: [`TilePakEntryLayout`](#tilepakentrylayout) — one per populated descriptor, 0x28 bytes

### `World/Floor.pak`

Linked floor-overlay records.

- Header: [`PakArchiveHeaderLayout`](#pakarchiveheaderlayout) — once, 0x100 bytes
- Entry descriptors: [`PakEntryDescriptorLayout`](#pakentrydescriptorlayout) — EntryCount times, 0xC bytes
- Floor records: [`FloorOverlayRecord`](#flooroverlayrecord) — one per populated descriptor, 0x10 bytes

### `World/Static.pak`

Linked static-world objects.

- Header: [`PakArchiveHeaderLayout`](#pakarchiveheaderlayout) — once, 0x100 bytes
- Entry descriptors: [`PakEntryDescriptorLayout`](#pakentrydescriptorlayout) — EntryCount times, 0xC bytes
- Static records: [`StaticObjectRecord`](#staticobjectrecord) — one per populated descriptor, 0x40 bytes

### `World/sectors.keyx`

- Header: [`KeyxHeaderLayout`](#keyxheaderlayout) — once, 0x100 bytes
- Sector records: [`KeyxSectorRecord`](#keyxsectorrecord) — SectorCount times, 0x300 bytes

### `World/sectors.wldx`

Compressed world-sector payloads.

- Outdoor and indoor tiles: [`WldxTileRecord`](#wldxtilerecord) — once per tile in a decompressed sector, 0x20 bytes
- Post-tile header: [`WldxPostTileHeaderLayout`](#wldxposttileheaderlayout) — once per decompressed sector, 0x24 bytes
- Indoor-grid descriptors: [`WldxIndoorGroupDescriptorLayout`](#wldxindoorgroupdescriptorlayout) — zero or more per sector, 0x24 bytes. The outer zlib stream and variable tile-array counts are excluded from fixed-layout coverage.

### `bin/sets.bin`

- Header: [`SacredSetHeaderLayout`](#sacredsetheaderlayout) — once, 0x4 bytes
- Set records: [`SacredSetEntryLayout`](#sacredsetentrylayout) — SetCount times, 0x70 bytes

- Cell associations: [`SacredStairsCellLayout`](#sacredstairscelllayout) — until end of file, 0x8 bytes

### `bin/**/DefPos.bin`

- First-table header: [`SacredDefPosHeaderLayout`](#sacreddefposheaderlayout) — once, 0x4 bytes
- Named positions: [`SacredDefPosPositionLayout`](#sacreddefpospositionlayout) — PositionCount times, 0x64 bytes. Later DefPos.bin tables are not yet represented by StructLayout types.

### `scripts/*/global.res`

- Header: [`GameResourceHeaderLayout`](#gameresourceheaderlayout) — once, 0x4 bytes
- String index: [`GameResourceIndexLayout`](#gameresourceindexlayout) — StringCount times, 0x10 bytes. Variable-length UTF-16 string data is referenced by the index and excluded from fixed-layout coverage.
